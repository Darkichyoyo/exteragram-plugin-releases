# MultiTools 3.3 — без удалённых

Отдельная сборка MultiTools, из которой полностью вырезана функция «Удалённые сообщения».

Убрано:
- сохранение и просмотр удалённых сообщений, архив и журнал;
- сохранение медиа из удалённых сообщений;
- пометки удалённых в чате, настройки внешнего вида;
- пункты меню «Посмотреть удалённые» / «Очистить удалённые» / «История»;
- страница настроек «Удалённые сообщения» и переключатель модуля.

Остались модули: Мут, Удаление, Спам, No Via, Команды, проверка обновлений.

Основная полная версия — `plugins/multi_tools/3.2/`. Манифест `releases.json` по-прежнему указывает на 3.2, эта сборка устанавливается только вручную.
